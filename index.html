작동 방식

ONTOH가 현장을 지키는 방법.

STEP 01

AI가 스스로 카메라를 제어

PTZ 카메라가 위험 구역을 자동 순찰하며 사각지대를 실시간 해소합니다. 수동 조작 없이 현장 전체를 커버.

  • 24시간 무인 자율 순찰
  • 위험 감지 시 자동 줌인
  • 기존 CCTV 장비와 호환
STEP 02

위험을 감지하고 맥락을 판단

단순 객체 인식을 넘어 RAG-LMM 복합 상황 판단으로 오경보를 줄이고 실제 위험만 정확히 알립니다.

  • 20,000+ 자체 학습 데이터
  • 다중 위험 동시 감지
  • 안전보건 법령 자동 매칭
STEP 03

근로자 건강까지 데이터로 관리

건강검진 결과를 자동 연동해 고위험군을 즉시 분류하고, 맞춤 보건 리포트로 질병형 재해까지 대응.

  • 건강검진 데이터 연동
  • 질환 민감군 자동 분류
  • 현장 맞춤 보건 리포트
