## 사용 정책
- 각 이미지의 **원본 출처 링크를 유지**하며, 상업적 재판매·재배포하지 않습니다.
- 저작권자로부터 삭제·수정 요청이 있을 경우 즉시 반영합니다.
- 나무위키 이미지(CC BY-NC-SA)의 상업 사용 여부는 별도 판단 필요.
- 신규 이미지 추가 시 이 파일에 출처와 확인 결과를 함께 기록합니다.
