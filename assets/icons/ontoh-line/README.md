# ONTOH Line Icons

ONTOH 홈페이지의 제품 기능 설명 및 홍보자료용 SVG 아이콘 세트입니다.

## 스타일

- ViewBox: `0 0 128 128`
- 기본 선: `#0A2440`, 5px
- 강조 선: `#0169A9`
- 강조 면: `#8ED0FF`
- 배경: 투명
- Line cap/join: round
- 그림자, 그라데이션, 외부 원형 배경 없음

## 아이콘

- `realtime-monitoring.svg` — 실시간 AI 현장 관제
- `hazard-detection.svg` — 위험 상황 자동 감지
- `ptz-tracking.svg` — PTZ 카메라 자율 추적
- `regulation-matching.svg` — 안전 규정 자동 매칭
- `report-automation.svg` — 점검 및 보고서 자동 생성
- `worker-health.svg` — 근로자 건강 정보 관리
- `work-fitness.svg` — 작업 적합성 판정
- `followup-care.svg` — 건강 이상 사후관리

웹의 버튼, 화살표, 체크 표시 등 작은 UI 아이콘은 기존 디자인 규칙에 따라
Iconify Solar를 계속 사용합니다. 이 세트는 제품 기능을 설명하는 큰 아이콘과
회사 소개서·제안서·브로슈어에 사용합니다.
