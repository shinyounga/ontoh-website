Process

감지부터 교육까지, 하나의 흐름으로.

CCTV 영상 수신부터 안전교육 자료 생성까지, 5단계 자동화 파이프라인이 현장 안전을 실시간으로 관리합니다.

01

CCTV 영상 수신

기존 CCTV 인프라를 그대로 활용합니다. 별도 장비 교체나 추가 설치가 필요 없습니다.

  • 별도 장비 불필요
  • 기존 인프라 그대로 활용
02

AI 실시간 객체 식별

작업자·장비·환경 요소를 실시간으로 식별하고, 위험 행동을 자동으로 감지합니다.

  • PPE 미착용 감지
  • 개구부 미설치 감지
  • 위험구역 침범 감지
03

RAG-LLM 규정 매칭

위험 상황을 관련 법령과 자동으로 대조하여, 위반 조항과 필요 조치를 즉시 안내합니다.

  • 위험 상황 → 관련 법령 자동 대조
  • 위반 조항·필요 조치 즉시 안내
04

PTZ 자율 제어 · Core

위험 감지 시 카메라가 자동으로 회전·줌인하여, 사각지대 없이 추적하고 기록합니다.

  • 위험 감지 시 자동 회전/줌
  • 사각지대 자동 추적
05

기록 / 알림 / 교육

전 과정을 자동으로 기록하고 관리자에게 실시간으로 알립니다. 현장 맞춤형 안전교육 자료까지 자동으로 생성합니다.

  • 전 과정 조치 기록
  • 관리자 실시간 알림
  • 맞춤형 안전교육 자료 생성

Comparison

상황을 해석하고, CCTV를 제어합니다.

단순 이벤트 감지에 머무르던 지능형 CCTV를 넘어, 상황을 이해하고 스스로 행동하는 관제 시스템으로 진화합니다.

  • —교육 자료 별도 제작 필요 — 추가 시간과 비용 소요

자동 생성되는 결과물

01

일일 위험 탐지 리포트

탐지 건수·유형·시간대별 패턴을 자동 정리한 일일 보고서.

  • 탐지 건수 / 유형별 분류
  • 조치 완료 / 미완료 현황
02

현장 맞춤형 안전교육 자료

실제 현장 영상과 관련 법령 조항을 조합한 맞춤형 교육 자료.

  • 실제 현장 영상 기반
  • 해당 법령 조항 연결
03

법적 증빙 자료

감지부터 조치까지 전 과정을 타임스탬프와 함께 기록해, 법적 분쟁 시 즉시 활용합니다.

  • 감지 — 조치 전 과정 기록
  • 타임스탬프 포함 영상 저장

Features

안전관리의 기준을 만듭니다.

AI 영상 분석, CCTV PTZ 자율 제어, 법령 매칭, 교육 자료 생성까지 — 건설현장 안전관리의 기준을 만듭니다.

01

AI 기반 CCTV 자동 제어 · Core

위험 상황이 감지되면 PTZ 카메라가 자동으로 해당 지점을 추적합니다. 관제 요원이 수동으로 카메라를 조작할 필요 없이, AI가 최적의 화각을 계산하여 카메라를 이동시키고 줌인합니다. 사각지대 없는 능동형 관제 체계를 구현합니다.

  • 자동 추적
  • 자동 줌인
  • 360도 커버
02

RAG-LLM 복합 상황 판단

단순 패턴 매칭이 아닌 RAG 기반 대형 언어 모델이 영상 속 상황을 종합적으로 판단합니다. 여러 위험 요소가 동시에 존재하는 복합 상황에서도 정확한 분석과 우선순위 판단이 가능합니다.

03

현장 맞춤형 안전 교육 자료 생성

실제 현장에서 발생한 위험 사례를 기반으로 교육 자료를 자동 생성합니다. 추상적인 교육이 아닌, 작업자가 매일 마주하는 현장의 실제 상황으로 안전 의식을 높입니다.

04

법령 / 규정 / 규칙 준수

산업안전보건기준에 관한 규칙 제43조(추락 방지), 제32조(보호구 착용) 등 관련 법령을 AI가 자동으로 매칭합니다. 위반 상황 발생 시 해당 법령 조항과 필요한 조치 사항을 즉시 안내하여, 현장의 법적 리스크를 사전에 차단합니다.

  • 산업안전보건법
  • 건설기술진흥법
  • 안전보건기준규칙 제43조 (추락 방지)
  • 제32조 (보호구 착용)

Compliance
