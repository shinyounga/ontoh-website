01

CCTV 영상 수신

기존 CCTV 인프라를 그대로 활용합니다. 별도 장비 교체나 추가 설치가 필요 없습니다.

  • 별도 장비 불필요
  • 기존 인프라 활용
02

AI 실시간 객체 식별

작업자·장비·환경 요소를 실시간으로 식별하고, 위험 행동을 자동으로 감지합니다.

  • PPE 미착용 감지
  • 개구부 미설치 감지
  • 위험구역 침범 감지
03

RAG-LLM 규정 매칭

위험 상황을 관련 법령과 자동으로 대조하여, 위반 조항과 필요 조치를 즉시 안내합니다.

  • 관련 법령 자동 대조
  • 위반 조항·조치 안내
04

PTZ 자율 제어 · Core

위험 감지 시 카메라가 자동으로 회전·줌인하여, 사각지대 없이 추적하고 기록합니다.

  • 자동 회전/줌
  • 사각지대 자동 추적
05

기록 / 알림 / 교육

전 과정을 자동으로 기록하고 관리자에게 실시간으로 알립니다. 현장 맞춤형 안전교육 자료까지 자동으로 생성합니다.

  • 전 과정 조치 기록
  • 관리자 실시간 알림
  • 맞춤형 교육 자료

Features

안전관리의 기준을 만듭니다.

AI 영상 분석, CCTV PTZ 자율 제어, 법령 매칭, 교육 자료 생성까지 — 건설현장 안전관리의 기준을 만듭니다.

AI 기반 CCTV 자동 제어 · Core

위험 상황이 감지되면 PTZ 카메라가 자동으로 해당 지점을 추적합니다. 관제 요원이 수동으로 카메라를 조작할 필요 없이, AI가 최적의 화각을 계산하여 카메라를 이동시키고 줌인합니다. 사각지대 없는 능동형 관제 체계를 구현합니다.

  • 자동 추적
  • 자동 줌인
  • 360도 커버

RAG-LLM 복합 상황 판단

단순 패턴 매칭이 아닌 RAG 기반 대형 언어 모델이 영상 속 상황을 종합적으로 판단합니다. 여러 위험 요소가 동시에 존재하는 복합 상황에서도 정확한 분석과 우선순위 판단이 가능합니다.

현장 맞춤형 안전 교육 자료 생성

실제 현장에서 발생한 위험 사례를 기반으로 교육 자료를 자동 생성합니다. 추상적인 교육이 아닌, 작업자가 매일 마주하는 현장의 실제 상황으로 안전 의식을 높입니다.

법령 / 규정 / 규칙 준수

산업안전보건기준에 관한 규칙 제43조(추락 방지), 제32조(보호구 착용) 등 관련 법령을 AI가 자동으로 매칭합니다. 위반 상황 발생 시 해당 법령 조항과 필요한 조치 사항을 즉시 안내하여, 현장의 법적 리스크를 사전에 차단합니다.

  • 산업안전보건법
  • 건설기술진흥법
  • 안전보건기준규칙 제43조 (추락 방지)
  • 제32조 (보호구 착용)

Compliance
