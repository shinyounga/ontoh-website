디지털 보건관리

근로자의 건강 위험을,
데이터로 먼저 살핍니다.

“보이지 않는 위험일수록, 먼저 찾아내야 합니다.”

고혈압·과로·폭염 같은 질병형 산업재해는 보이지 않게 다가옵니다. 온토케어는 흩어진 검진 데이터를 자동으로 모아, 고위험군을 먼저 찾아냅니다.

데모 신청 작동 방식 보기

기존 검진 데이터 연동 · 현장 규모에 맞춘 무료 데모 제공

문제 인식

검진 결과부터 작업 관리까지, 전 과정이 수기·분절입니다.

건강검진 → 결과 수령 → 엑셀 입력 → 개별 관리 → 고위험군 식별까지, 모든 단계가 끊겨 있어 사후 대응에 그칩니다.

건강검진 결과

PDF·엑셀로 개별 관리되고 현장마다 양식이 달라 통합 조회가 불가능합니다. 작업자가 늘수록 관리 난이도가 급증합니다.

배치 시 건강상태 확인

검진 결과와 배치 정보를 수기로 대조해 확인 누락이 잦고, 건강 이상 작업자가 고위험 작업에 배치되는 사각지대가 생깁니다.

고위험군 식별

관리자 개인의 경험과 역량에 의존해 체계적 기준 없이 판단하므로, 고위험 작업자 사전 식별에 반복적으로 실패합니다.

수기 업무 흐름

우편·PDF 수령과 엑셀 수기 입력으로 오타·누락이 빈번하고, 데이터가 파편화되어 통합 조회가 어렵습니다.

작동 방식

반복 업무는 AI에게,
관리자는 핵심 업무에.

인증부터 사후관리까지, 전 과정을 하나의 플랫폼에서 자동으로 처리합니다.

01

간편 인증

본인 확인 한 번으로 시작합니다. 카카오·네이버·PASS 간편인증을 지원합니다.

02

데이터 수집

검진 기관과 연동해 10년치 국가건강검진 결과를 자동으로 수집합니다.

03

위험 분류

AI가 고위험군을 판별해 고혈압·당뇨·심뇌혈관 위험을 자동으로 분류합니다.

04

리포트

현장별·개인별 보건 리포트를 자동 생성하고 엑셀 출력을 지원합니다.

05

사후 관리 추적

건강 이력을 모니터링하고 재검사·작업전환 리마인드를 자동 발송합니다.

주요 기능

등록부터 관리까지, 모든 기능을 하나로.

작업자 등록 & 검진 자동 수집

작업자가 간편인증을 완료하면 국가건강검진 결과가 자동으로 수집됩니다. 관리자는 별도 입력 없이 대시보드에서 전체 현황을 확인하고, 10년치 이력으로 과거 추이까지 분석할 수 있습니다.

  • 카카오·네이버·PASS 간편인증 지원
  • 10년치 국가건강검진 결과 자동 연동
  • 수기 입력 완전 제거, 오류율 0%

관리자를 위한 핵심 기능

작업자 건강 상태를 한눈에 파악하고, 필요한 조치를 바로 확인합니다. 등록 작업자·고위험군·미등록자 현황을 실시간으로 집계합니다.

민감군 대시보드
현장별 고위험군 현황을 실시간으로 파악합니다.
미등록자 알림
미등록 작업자를 자동 식별하고 등록을 독촉합니다.
유해인자별 검진결과 조회
유해인자별 건강구분과 조치 현황을 확인합니다.
엑셀 출력 & 조치완료 체크
기존 보고 양식과 호환되는 엑셀 출력과 조치 이행 체크를 지원합니다.

보건 리포트

공단 검진 데이터를 한눈에 정리합니다.

국민건강보험공단 검진 결과를 기반으로 건강 상태를 시각화하고, 흩어진 데이터를 모아 작업자가 자신의 건강을 쉽게 이해하도록 정리합니다.

관리자는 대시보드에서 전체 현황을, 작업자는 모바일 앱에서 개인 건강 리포트와 현장 배치용 QR 체크인을 확인합니다.

건강나이

공단 검진 기반 건강나이를 직관적으로 표시합니다.

심뇌혈관 위험 예측

3년 내 발병 확률과 위험 요인을 분석합니다.

유사집단 비교

동일 연령·성별·직종 집단과 비교합니다.

연도별 건강 추이

10년간 검진 이력을 시계열로 시각화합니다.

유해인자 매핑

직종을 선택하면, 유해인자가 자동 매핑됩니다.

공종과 직종을 선택하면 노출 유해인자 목록이 자동으로 설정됩니다. 관리자가 일일이 찾을 필요 없이 유해인자별 검진 항목과 관리 기준이 즉시 연동됩니다.

  • 공종·직종 선택만으로 유해인자 자동 설정
  • 유해인자별 필요 검진 항목 즉시 확인
  • 관리 기준과 검진 주기 자동 연동
