## 1. 색상·대비 (WCAG 1.4.3, 1.4.6)

### 사이트에서 사용하는 조합의 대비율

| 전경 | 배경 | 대비율 | 등급 |
|---|---|---|---|
| Ink `#0A2440` | White `#FFFFFF` | **14.87 : 1** | AAA |
| Body `#212121` | White `#FFFFFF` | **16.13 : 1** | AAA |
| Sub `#555555` | White `#FFFFFF` | **7.46 : 1** | AAA |
| Accent `#0169a9` | White `#FFFFFF` | **5.68 : 1** | AA |
| Success `#137a52` | White `#FFFFFF` | **4.76 : 1** | AA |
| Error `#c62828` | White `#FFFFFF` | **5.94 : 1** | AA |
| Warning `#c77700` | White `#FFFFFF` | **4.63 : 1** | AA (large text 위주 권장) |
| Info `#0169a9` | White `#FFFFFF` | **5.68 : 1** | AA |
| White | Ink `#0A2440` | **14.87 : 1** | AAA |
| White | Accent `#0169a9` | **5.68 : 1** | AA |

**기준선**: WCAG AA
- 본문 (일반 텍스트): **4.5 : 1** 이상
- 대형 텍스트 (18pt / 14pt bold+): **3 : 1** 이상

### Do
- 밝은 배경 + Ink · Body · Sub (다 통과)
- Ink 배경 + White (완벽 대비)
- Accent (link, CTA text) — 4.5:1 통과

### Don't
- Sub `#555` on Band `#F5F6F8` — 7.02:1 (통과이나 대형 텍스트 권장)
- 색상만으로 정보 전달 (`색상 외의 방법으로 상태 구분` 규정 참고)
- Warning `#c77700` on White — 본문 크기 사용 시 대비 부족 (반드시 대형 텍스트 · 또는 배경 반전)

## 2. 키보드·Focus (WCAG 2.1.1, 2.4.7)

### Focus 스타일

모든 페이지의 `<style>`에 다음 규칙이 있어야 함:

```css
:focus-visible {
  outline: 3px solid #0169a9;
  outline-offset: 2px;
  border-radius: 0;
}
:focus:not(:focus-visible) { outline: none; }
```

- 3px · 실선 · Accent 컬러 · 2px offset
- `:focus-visible` 사용 → 마우스 클릭 시 outline 안 뜨고 키보드 탐색 시만 뜸

### 키보드 탐색 규칙
- `Tab` → 모든 인터랙티브 요소 순회
- `Enter` → 링크·버튼 활성화
- `Space` → 버튼 활성화
- `Esc` → Lightbox 닫기
- `←` / `→` → Lightbox 그룹 내 이동 (Feature 04 캐러셀 포함)

### Skip to content 링크
모든 페이지 최상단에 스킵 링크:

```html
<a href="#main" class="skip-to-content">본문 바로가기</a>
```

CSS:
```css
.skip-to-content {
  position: absolute; top: -100px; left: 0;
  background: #0A2440; color: #fff;
  padding: 12px 20px; font-weight: 700; z-index: 100;
  transition: top 200ms cubic-bezier(0.16, 1, 0.3, 1);
}
.skip-to-content:focus { top: 0; }
```

## 3. 상태 표시 (WCAG 1.4.1)

### 색상 외 방법 병행 (필수)

| 상태 | 색상 | 아이콘 | 텍스트 |
|---|---|---|---|
| Error | 빨강 `#c62828` | `solar:danger-triangle-bold` | "오류" · "실패" |
| Warning | 주황 `#c77700` | `solar:info-circle-bold` | "주의" |
| Success | 녹색 `#137a52` | `solar:check-circle-bold` | "완료" · "성공" |
| Info | Accent | `solar:info-circle-linear` | "안내" |

### Do
```html
<div class="alert alert-success">
  <iconify-icon icon="solar:check-circle-bold"></iconify-icon>
  <b>전송 완료</b> · ONTOH 담당자가 24시간 내로 답변 드립니다.
</div>
```

### Don't
```html
<!-- ❌ 색상만으로 오류 표시 -->
<p style="color: red">전송 실패</p>
```

## 4. 터치·클릭 영역 (WCAG 2.5.5)

### 최소 크기
- **44 × 44 px** 이상 (WCAG 2.1 AAA · 모바일 필수)

### 사이트 적용 현황
| 컴포넌트 | 실제 크기 | 통과 |
|---|---|---|
| `.btn.btn-md` | ~52px | ✅ |
| `.btn.btn-sm` | ~40px + 여백 | ✅ (인접 요소와 여백 확보 시) |
| `.bc-cell` (Breadcrumb) | 48 × 48 px | ✅ |
| Form input (`.form-input`) | ~52px | ✅ |
| GNB nav item | ~48px | ✅ |
| Iconify 아이콘 (단독 링크) | 최소 24px + `p-2` 이상 | ✅ |

### Do
- 아이콘만 있는 버튼도 `p-3` 이상 (총 40px 이상)
- 인접한 클릭 요소 사이 최소 8px 여백

### Don't
- 40px 미만 클릭 영역
- 링크·버튼을 서로 붙여 배치 (모바일 오터치)

## 5. 텍스트·다국어

### 언어 선언
```html
<html lang="ko">
```
전체 페이지 필수 · 현재 30개 파일 준수.

### 긴 텍스트 대응
- 카드·태그·버튼 텍스트는 **`글자 수 규칙`** 준수 (components.md)
  - Kicker: 5-15자
  - H3: 5-15자
  - 버튼: 6-10자 (최대 15자)
  - Tag: 2-8자
- 이 범위 내에서는 어떤 언어로 번역해도 대체로 안전
- 특별히 긴 이름은 `text-balance` · `text-wrap` 유틸 사용

### 폰트
- Pretendard · 한글/영문 통합 · 국제 문자 대부분 지원
- 다국어 확장 시 Pretendard Std / JP / TC 등 지역별 서브패밀리로 확장 가능

### 이미지 대체 텍스트
- 정보 이미지: 의미 설명 (`alt="온토비전 대시보드 · 5대 현장 위험 유형 실시간 카드"`)
- 장식 이미지: 빈 alt (`alt=""`)
- 로고: 회사명 (`alt="ONTOH"`)

## 6. 반응형

### 브레이크포인트 (Tailwind 기본)
| 이름 | 최소 폭 | 사용처 |
|---|---|---|
| default | 0 | 모바일 (기본) |
| `sm:` | 640px | 소형 태블릿 |
| `md:` | 768px | 태블릿 · 세로 |
| `lg:` | 1024px | 노트북 · 태블릿 가로 |
| `xl:` | 1280px | 데스크톱 |
| `2xl:` | 1536px | 대형 모니터 (필요 시) |

### 여백 위계 규칙
| 위치 | 모바일 | 데스크톱 |
|---|---|---|
| 섹션 상하 | `py-16` (64px) | `md:py-24` (96px) |
| 헤더 → 콘텐츠 | `mb-14` | `md:mb-16` |
| 카드 내부 | `p-6` | `md:p-7 / md:p-8` |
| 컨테이너 폭 | 100% - 32px | `max-w-[1200px] · mx-auto` |

### 뷰포트 (필수)
```html
<meta name="viewport" content="width=device-width, initial-scale=1">
```
- `min-h-[100dvh]` 사용 (mobile Safari 대응 · CLAUDE.md 규정)
- `h-screen` 금지

### 반응형 이미지
```html
<img src="/assets/vision/main.png" alt="..." class="w-full h-auto">
```
- `w-full h-auto` 조합으로 컨테이너에 맞춤
- 큰 이미지는 `object-cover` · `object-position` 활용

## 7. 시맨틱 마크업 (WCAG 1.3.1, 4.1.2)

### 랜드마크 요소 (필수)
```html
<body>
  <a href="#main" class="skip-to-content">본문 바로가기</a>
  <header>...</header>          <!-- GNB · 로고 -->
  <main id="main">...</main>    <!-- 페이지 본문 -->
  <footer>...</footer>          <!-- 회사정보 · 링크 -->
</body>
```

### 헤딩 계층 (WCAG 1.3.1)
- 페이지당 `<h1>` 1개
- `<h1>` → `<h2>` → `<h3>` 순서 유지 · 건너뛰기 금지
- 시각적 크기와 시맨틱 레벨은 다를 수 있음 (`.text-h1` 클래스로 조정)

### 폼 필드
```html
<label for="company" class="form-label">
  회사명·기관명 <span class="required">*</span>
</label>
<input id="company" type="text" class="form-input" required 
       aria-describedby="company-help">
<p id="company-help" class="text-caption text-sub">공식 명칭을 적어주세요.</p>
```

### 아이콘
- Iconify Solar 아이콘은 기본 `aria-hidden`
- 아이콘만 있는 버튼: `aria-label="메뉴 닫기"` 필수

## 8. 모션 감소 · Reduced Motion (WCAG 2.3.3)

### 모든 페이지 CSS에 추가

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

- 사용자가 OS 설정에서 "동작 최소화"를 켠 경우 모든 애니메이션 · 트랜지션 사실상 제거
- 캐러셀 자동 재생도 정지 (`.lc-viewport.playing` 등도 별도 처리 권장)

## 9. 점검 방법

### 자동 도구
- **Chrome DevTools · Lighthouse** — Accessibility 점수 (95+ 유지)
- **axe DevTools** (Chrome 확장) — WCAG 위반 자동 감지
- **WebAIM Contrast Checker** — 색상 대비 실측

### 수동 점검
1. **키보드만 사용** — `Tab` · `Enter` · `Esc` · 화살표
2. **화면 확대 200%** — 텍스트 · 이미지 · 레이아웃 유지
3. **화면 축소 320px 폭** — 가로 스크롤 없이 콘텐츠 접근
4. **스크린 리더** — NVDA (Windows · 무료) · VoiceOver (Mac)
5. **색상 시뮬레이션** — Chrome DevTools · Rendering · Emulate vision deficiencies

### CI · 배포 전 필수 체크
- Lighthouse Accessibility ≥ 95
- axe 오류 0개
- 신규 페이지 추가 시 → 이 문서의 목차 1~8 순회 점검
