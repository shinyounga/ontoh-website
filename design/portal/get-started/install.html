Get Started

Install · Use

ONTOH 디자인 시스템을 새 페이지에 적용하는 방법. 5분 셋업 · CDN 기반 · 빌드 도구 없음.

Quick Start · 5분

  1. 기존 페이지 (예: about.html) 복제 · 파일명 변경
  2. <title> · <meta name="description"> 변경
  3. 본문 콘텐츠 교체 (Kicker + H2 + Section 패턴)
  4. Breadcrumb 셀 대메뉴·중메뉴 명 변경
  5. 헤더·푸터 그대로 유지 (전 페이지 공용)

필수 head 요소

<!DOCTYPE html>
<html lang="ko">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>페이지 이름 · ONTOH</title>
  <meta name="description" content="한 줄 설명">

  <!-- Pretendard 폰트 -->
  <link rel="stylesheet"
        href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard/dist/web/static/pretendard.min.css">

  <!-- Tailwind CDN -->
  <script src="https://cdn.tailwindcss.com"></script>

  <!-- Iconify Solar -->
  <script src="https://code.iconify.design/iconify-icon/2.3.0/iconify-icon.min.js"></script>

  <script>
    tailwind.config = { /* config extend · Integration 페이지 참조 */ };
  </script>

  <style>
    /* 페이지별 커스텀 CSS · .btn · .card · .kicker 등 */
    /* about.html 참조하여 복사 */
  </style>
</head>

필수 body 구조

<body class="bg-white font-sans antialiased">

  <!-- Skip-to-content (WCAG 2.4.1) -->
  <a href="#main" class="skip-to-content">본문 바로가기</a>

  <!-- Header · GNB (about.html 그대로 복사) -->
  <header class="sticky top-0 z-40 bg-white border-b border-hair">
    <!-- 로고 · 4 대메뉴 · CTA -->
  </header>

  <!-- Breadcrumb 스트립 -->
  <section class="bg-ink border-b border-white/10">
    <div class="bc-row">
      <div class="bc-cell bc-home">
        <iconify-icon icon="mdi:home"></iconify-icon>
      </div>
      <div class="bc-cell bc-menu">대메뉴</div>
      <div class="bc-cell bc-menu is-current">현재 페이지</div>
    </div>
  </section>

  <!-- Main content · id="main" 필수 -->
  <main id="main">
    <!-- 히어로 -->
    <section class="hero-bg-fixed py-24 md:py-32">...</section>
    <!-- 본문 섹션들 (Kicker + H2 + Content) -->
    <section class="py-16 md:py-24">...</section>
  </main>

  <!-- Footer (about.html 그대로 복사) -->
  <footer class="bg-[#E9ECEF] text-sub border-t border-hair">...</footer>

  <!-- Reduced motion (WCAG 2.3.3) 자동 지원 -->
</body>

새 페이지 첫 커밋 체크리스트

  1. ✅ <title> 페이지 이름 · meta description 채움
  2. ✅ <html lang="ko">
  3. ✅ Skip-to-content 링크 첫 요소
  4. ✅ <main id="main"> 본문 wrap
  5. ✅ 모든 이미지에 alt 속성
  6. ✅ 폼 있으면 <label for> 매칭
  7. ✅ 미완성 <!-- ... --> · 플레이스홀더 없음
  8. ✅ Iconify Solar만 사용 (이모지 X)
  9. ✅ Kicker · H2 · Section 조합 준수

사이트맵 갱신

새 페이지 추가 시 sitemap.xml 에 URL 추가:

<url>
  <loc>https://ontoh.co.kr/신규-페이지.html</loc>
  <lastmod>2026-07-29</lastmod>
  <changefreq>monthly</changefreq>
</url>

GNB 대메뉴 추가 (신중히)

대메뉴 4개는 고정 (회사소개 · 제품소개 · 기술·연구 · 문의). 신규 추가는 별도 논의 · 중메뉴로 편성 가능한지 먼저 검토.

  • 중메뉴로 처리 가능 → 해당 대메뉴의 dropdown-link에 추가
  • 대메뉴 자체 확장 필요 → 사이트 정보 구조 재검토
