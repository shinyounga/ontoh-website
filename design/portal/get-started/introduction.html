Introduction

ONTOH Design System은 주식회사 온토의 웹사이트 전반을 관통하는 브랜드 · 색상 · 타이포 · 컴포넌트 · UI 키트의 단일 진실 소스입니다. 새 페이지를 만들거나 기존 페이지를 수정할 때 여기부터 봅니다.

30초 요약

시재건설급 대형 건설사 톤 — 정연 · 절제 · 기관형. 색은 딥네이비 #0A2440와 온토 블루 액센트 #0169a9의 조합. 폰트 하나 (Pretendard), 아이콘 하나 (Iconify Solar), 스타일 하나 (Tailwind CDN).

브랜드 파운데이션

Color

  • Ink #0A2440 — 딥네이비 · 헤드라인 · 헤더
  • Body #212121 — 차콜 · 본문
  • Sub #555555 — 보조 텍스트
  • Accent #0169a9 — 온토 블루 · 링크 · CTA · 수치
  • Band #F5F6F8 — 오프화이트 · 섹션 구분
  • Hair #E5E7EB — 헤어라인 · 테두리

Type

Pretendard 단일 (한국어 필수). Inter · Noto Sans KR · 명조체 사용 금지.

Shape

  • 직각 (rounded-none) — 라운드 지양
  • 헤어라인 중심 — 큰 그림자 자제
  • 여백으로 위계 — 볼드 남발 금지

금지 사항

  • 웜 아이보리 · 쿨 그레이 틴트 · 다크 배경 (본문)
  • 이모지 → Iconify Solar로 대체
  • ease-in-out / linear 트랜지션 → cubic-bezier(0.16, 1, 0.3, 1)
  • 보라색 · 네온 · AI 그라디언트
  • AI 클리셰 한국어: "혁신적인", "원활한", "차세대", "게임 체인저"
  • 지어낸 수치 (없으면 "실증 진행 중"으로 표기)

사용 방법

새 페이지를 만들 때:

  1. Principles를 먼저 읽습니다
  2. Foundations에서 토큰 값을 참조합니다
  3. Components에서 필요한 컴포넌트 HTML을 복사합니다
  4. Pretendard + Tailwind CDN + Iconify 스크립트를 로드합니다
  5. 헤더 · 푸터는 about.html의 것을 재사용합니다 (자세히 · Install)
