Integration

새 페이지를 만들거나 ONTOH 디자인 시스템을 프로젝트에 통합하는 방법. Tailwind CDN + Pretendard + Iconify Solar 스택.

Quick Start · 5분 셋업

  1. 기존 페이지 (예: about.html) 를 복제 · 이름 변경
  2. <title> · <meta name="description"> 변경
  3. 본문 콘텐츠 교체 (Kicker + H2 + Section)
  4. Breadcrumb 셀 (.bc-cell) 대메뉴·중메뉴 명 변경
  5. 헤더·푸터 그대로 유지 (전 페이지 공용)

필수 리소스 (모든 페이지 head)

<!-- Pretendard 웹폰트 -->
<link rel="stylesheet"
      href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard/dist/web/static/pretendard.min.css">

<!-- Tailwind CDN -->
<script src="https://cdn.tailwindcss.com"></script>

<!-- Iconify Solar -->
<script src="https://code.iconify.design/iconify-icon/2.3.0/iconify-icon.min.js"></script>

<!-- 공통 CSS (선택 · 사이트 페이지에는 인라인 style 사용) -->
<link rel="stylesheet" href="css/common.css">

<!-- 접근성 · 필수 -->
<html lang="ko">
<meta name="viewport" content="width=device-width, initial-scale=1">

필수 접근성 (모든 페이지)

  1. <a href="#main" class="skip-to-content">본문 바로가기</a> — body 첫 요소
  2. <main id="main">...</main> — 본문 wrap
  3. prefers-reduced-motion CSS 규칙 포함
  4. <html lang="ko"> · 이미지 alt · 폼 label
