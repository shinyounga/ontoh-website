GNB 메가메뉴 + Breadcrumb 스트립. Sticky · 92px 높이 · 대메뉴 4개 고정.

GNB · Global Navigation Bar

클래스용도
.nav-item탑 메뉴 아이템 컨테이너
.nav-top탑 메뉴 텍스트 · Hover 시 밑줄 slide
.nav-panel메가메뉴 패널 · Hover 시 확장
.gnb-megabar메가메뉴 컨테이너
.gnb-panel-box메가메뉴 링크 그룹

구조

  • 위치: sticky top-0 · 92px 높이
  • 대메뉴 4개 고정: 회사소개 · 제품소개 · 기술·연구 · 문의
  • 중메뉴: 각 대메뉴 하위 1-4개 이내

Breadcrumb Strip

  • GNB 아래 얇은 남색 스트립 (48px)
  • 홈 → 대메뉴 → 중메뉴 순서
  • 3단계 초과 지양
  • Cross-link: Breadcrumb 컴포넌트

Sitemap Rules

  • 대메뉴 4개 고정 · 신규 추가는 별도 논의
  • 중메뉴: 각 대메뉴 하위 1-4개 이내 · 5개 초과 시 재편성
  • 드롭다운 링크 텍스트: 대메뉴명 동일 · 4-10자

모바일 대응

  • 1024px 이하: 햄버거 메뉴로 전환
  • Off-canvas 사이드바 · 배경 backdrop
  • Sticky 유지 · 스크롤 시에도 접근 가능

접근성

  • 드롭다운은 aria-expanded 상태 반영
  • 키보드 Tab · Enter · Esc 완전 지원
  • 현재 페이지는 aria-current="page"
