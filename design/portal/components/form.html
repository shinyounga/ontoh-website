Components

Form

사용자 입력 수집. contact.html 전용. Formspree 백엔드 사용. Label · Input · Textarea · Checkbox · State 조합.

Property

클래스용도
.form-label레이블 · 명사 (예: "회사명·기관명")
.form-inputtext · email · tel input · min-height 52px
.form-textarea여러 줄 텍스트 · min-height 120px
.form-checkbox동의 체크박스
.form-state.success성공 · 초록
.form-state.error오류 · 빨강
.honeypot스팸 방지 숨김 필드

사용 규칙

  • 필수 필드 → HTML5 required 속성 + <span class="required">*</span>
  • 에러는 .alert-error 또는 .form-state.error
  • Placeholder 형식: 예) ○○주식회사
  • Label · Input 반드시 for/id 매칭 (a11y)

Do

<label for="company" class="form-label">
  회사명·기관명 <span class="required">*</span>
</label>
<input id="company" type="text" class="form-input" required
       placeholder="예) ○○주식회사"
       aria-describedby="company-help">
<p id="company-help" class="text-caption text-sub">공식 명칭을 적어주세요.</p>

Don't

✗ Label 없는 Input · Placeholder만으로 Label 대체 (a11y 위반) · 자동 focus (사용자 흐름 방해)
