Focus Visible (WCAG 2.4.7 · 필수)

:focus-visible {
  outline: 3px solid #0169a9;
  outline-offset: 2px;
  border-radius: 0;
}
:focus:not(:focus-visible) { outline: none; }
  • 3px 실선 · Accent 컬러 · 2px offset
  • 마우스 클릭 시 outline 안 뜨고 (`:focus`) · 키보드 탐색 시만 뜸 (`:focus-visible`)
  • 모든 인터랙티브 요소 (button · a · input · select · textarea)

Reduced Motion (WCAG 2.3.3)

사용자가 OS "동작 최소화" 설정 시 모든 애니메이션·트랜지션 사실상 제거.

@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
