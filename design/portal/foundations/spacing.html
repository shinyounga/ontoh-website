Spacing

Tailwind 기본 spacing scale 사용. 커스텀 spacing 정의 없음. 여백이 위계 — ONTOH는 큰 그림자·볼드 대신 여백으로 정보 위계를 만듭니다.

기본 스케일

Tailwind의 4px 배수 (0.25rem) 기반. 자주 쓰는 단위:

gap-2 8px
gap-3 12px
gap-4 16px
p-6 24px
p-7 28px
p-8 32px
p-10 40px
py-14 56px
py-16 64px
py-24 96px
py-28 112px
py-32 128px

여백 위계 규칙

위치모바일데스크톱
섹션 상하 py-16 md:py-24
헤더 → 콘텐츠 mb-14 md:mb-16
카드 내부 padding (본문 적은 카드) p-6 md:p-7
카드 내부 padding (본문 많은 카드) p-7 md:p-8 / md:p-10
텍스트 gap (inline) gap-2 gap-3

Container 폭

  • 모바일: 100% - 32px 여백 (좌우 px-4)
  • 데스크톱: max-w-[1200px] · mx-auto · 좌우 px-6 sm:px-10 lg:px-14

Viewport

<meta name="viewport" content="width=device-width, initial-scale=1">
  • min-h-[100dvh] 사용 (mobile Safari 대응 · CLAUDE.md 규정)
  • h-screen 금지

사용 예시

<!-- 표준 섹션 -->
<section class="py-16 md:py-24 border-t border-hair">
  <div class="max-w-[1200px] mx-auto px-6 sm:px-10 lg:px-14">
    <p class="kicker mb-4">섹션 라벨</p>
    <h2 class="text-h2 font-bold mb-14 md:mb-16">섹션 헤드</h2>
    <!-- 콘텐츠 -->
  </div>
</section>
