Elevation

그림자(box-shadow) semantic scale · 4단계. 색상은 항상 rgba(10, 36, 64, alpha) — Ink 컬러 기반. 새 그림자 정의 금지 · 아래 4가지 중 선택합니다.

Semantic Shadow Scale

클래스값용도
shadow-card 0 18px 40px -22px rgba(10,36,64,0.32) 카드 hover
shadow-panel 0 24px 44px -20px rgba(10,36,64,0.35) 드롭다운 패널
shadow-megabar 0 28px 46px -26px rgba(10,36,64,0.30) GNB 메가메뉴
shadow-lightbox 0 40px 80px -20px rgba(10,36,64,0.5) Lightbox 모달

사용 규칙

  • 새 그림자 정의 금지 · 4가지 semantic scale 중 선택.
  • 색상은 항상 rgba(10, 36, 64, alpha) (ink 컬러 기반) · black 사용 금지.
  • 기본 상태 X · hover · panel · modal에만.
  • 큰 그림자 남발 금지 — 헤어라인이 우선.

Tailwind 사용 예시

<!-- 카드 (hover 시 그림자) -->
<article class="card hover:shadow-card">...</article>
<!-- .card 컴포넌트가 이미 shadow-card 를 포함 -->

<!-- 드롭다운 패널 -->
<div class="nav-panel shadow-panel">...</div>

<!-- Lightbox 모달 -->
<dialog class="lb-dialog shadow-lightbox">...</dialog>
