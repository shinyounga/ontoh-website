WCAG 2.1 접근성 대비

사이트에서 실제 사용되는 배경-전경 조합의 대비율 실측 (WCAG AA 기준 4.5:1 이상 · AAA 기준 7:1 이상).

전경배경대비율등급
Ink #0A2440 White #FFFFFF 14.87 : 1 AAA
Body #212121 White #FFFFFF 16.13 : 1 AAA
Sub #555555 White #FFFFFF 7.46 : 1 AAA
Accent #0169a9 White #FFFFFF 5.68 : 1 AA
Success #137a52 White #FFFFFF 4.76 : 1 AA
Error #dc2626 White #FFFFFF 4.83 : 1 AA
Warning #ea580c White #FFFFFF 3.36 : 1 Large text · Deco only
White Ink #0A2440 14.87 : 1 AAA

Alert 컴포넌트 실제 텍스트 컬러: error #7f1d1d on #fef2f2 (~11.5:1 AAA) · warning #7c2d12 on #fff7ed (~10.3:1 AAA) · success #14532d on #f0fdf4 (~10.8:1 AAA)

사용 규칙

  • 로고 SVG 안에서만 navy #1b2e6a 사용. 웹 UI에는 항상 ink.
  • 강조는 accent 하나로 통일. 여러 색 혼용 금지.
  • State 컬러 (error · warning · success · info) 는 상태 표현(Alert · Tag)에만 사용.
  • 임의 hex 값 사용 금지 · 필요 시 이 문서에 토큰 추가 논의 후 사용.
State 컬러 사용 제한 (2026-07-29 확정) · error · warning 는 데코 요소 (border-left · icon · background) 만 사용 · 본문 텍스트로는 진한 톤 (`#7f1d1d` · `#7c2d12` · `#14532d`) 사용. warning #ea580c 는 대비 3.36:1로 큰 텍스트만 안전.

Tailwind 사용 예시

<!-- Primitive tokens -->
<div class="bg-ink text-white">딥네이비 배경</div>
<p class="text-body">본문 텍스트</p>
<p class="text-sub">보조 텍스트</p>
<a class="text-accent">링크</a>
<section class="bg-band border-t border-hair">섹션 밴드</section>

<!-- Semantic state -->
<div class="alert-error">오류</div>
<div class="alert-success">완료</div>
