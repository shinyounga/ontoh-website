Accessibility

WCAG 2.1 Level AA 기준. 모든 사용자가 접근 가능한 웹을 만들기 위한 원칙과 실무 규칙. 부분적으로 AAA (색상 대비 등) · 신규 페이지 · 컴포넌트 필수 준수.

기준선 · WCAG 2.1 AA

  • 본문 (일반 텍스트): 대비 4.5:1 이상
  • 대형 텍스트 (18pt / 14pt bold+): 대비 3:1 이상
  • UI 컴포넌트: 3:1 이상
  • Focus 표시: 시각적 명확
  • 키보드 완전 접근 가능

색상 대비 (WCAG 1.4.3, 1.4.6)

사이트에서 사용하는 조합의 실측 · 상세는 Color.

전경 / 배경대비율등급
Ink #0A2440 on White14.87 : 1AAA
Body #212121 on White16.13 : 1AAA
Sub #555 on White7.46 : 1AAA
Accent #0169a9 on White5.68 : 1AA

키보드 · Focus (WCAG 2.1.1, 2.4.7)

  • Tab → 모든 인터랙티브 요소 순회
  • Enter → 링크·버튼 활성화
  • Space → 버튼 활성화
  • Esc → Lightbox · Modal 닫기
  • ← / → → Lightbox 그룹 내 순환

Focus 스타일 · State 페이지 참조.

Skip to Content (WCAG 2.4.1)

모든 페이지 최상단에 스킵 링크 필수:

<a href="#main" class="skip-to-content">본문 바로가기</a>

시맨틱 랜드마크 (WCAG 1.3.1, 4.1.2)

<body>
  <a href="#main" class="skip-to-content">본문 바로가기</a>
  <header>...</header>             <!-- GNB · 로고 -->
  <main id="main">...</main>       <!-- 페이지 본문 (id 필수) -->
  <footer>...</footer>             <!-- 회사정보 · 링크 -->
</body>

이미지 대체 텍스트

  • 장식 이미지: 빈 alt (alt="")

폼 필드 (WCAG 1.3.1)

  회사명·기관명 <span class="required">*</span>
</label>
<input id="company" type="text" class="form-input" required
       aria-describedby="company-help">
<p id="company-help" class="text-caption text-sub">공식 명칭을 적어주세요.</p>
